# Opakapaka quickstart model inputs

Builds the data, parameter, and map configuration used by the Opakapaka
quickstart assessment.

## Usage

``` r
opaka_quickstart_inputs()
```

## Value

A list with `data`, `parameters`, and `map` elements.
