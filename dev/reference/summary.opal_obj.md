Summarise a staged Opal assessment

``` r

print(x, ...)

```

## Arguments

- ...:

  Unused arguments.

- x, object:

  An `opal_obj` or its summary.

## Value

[`summary()`](https://rdrr.io/r/base/summary.html) returns a compact
list; print methods return invisibly.
