# Retrieve a stored assessment analysis

Retrieve a stored assessment analysis

## Usage

``` r
opal_derived(x, name)
```

## Arguments

- x:

  An `opal_obj`.

- name:

  Name of the analysis under `x$derived`.

## Value

The stored result after checking source identity and integrity.
